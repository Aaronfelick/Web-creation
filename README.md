# BizBot Premium Website

React, Tailwind CSS, and Framer Motion foundation for the new BizBot website.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Design system

- `tailwind.config.js` defines the premium dark canvas, electric orange signature color, custom gradients, shadows, and backdrop blur variants.
- `src/components/Navbar.jsx` contains the responsive glassmorphic navigation.
- `src/components/Button.jsx` provides the universal frosted glass button variant component.
- `src/components/GlassLayout.jsx` contains reusable glassmorphic layout wrappers.
